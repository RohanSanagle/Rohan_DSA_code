Supermarket Customer Queue Using Linked List

Project Description

This project is a simple customer queue management system for a supermarket developed using C++. It uses a Singly Linked List to manage customers waiting for service.

The program follows the FIFO (First In, First Out) principle, which means the customer who arrives first is served first.

Problem Statement

To develop a C++ program to manage a supermarket customer queue using a Singly Linked List. The program allows users to add customers, serve the next customer, and display the current queue.

Features

- Add a customer to the queue
- Serve the first customer in the queue
- Display all customers waiting in the queue
- Exit the program

Concepts Used

- C++ Programming
- Pointers
- Singly Linked List
- Dynamic Memory Allocation
- Queue Operations (Enqueue and Dequeue)
- FIFO Principle

Programming Language

C++

How to Run

1. Download the source code.
2. Open the file in a C++ compiler.
3. Compile and run the program.

Example using GCC:

g++ supermarket_queue.cpp -o supermarket_queue
./supermarket_queue

Learning Outcomes

This project helps understand the implementation of a queue using a linked list, pointer manipulation, and dynamic memory management in C++.

Conclusion

The project demonstrates a simple and efficient way to manage supermarket customers using a queue data structure.
